# AI Trader Agent

AI Trader Agent is an agentic AI trading application I developed during my Agentic AI Development Internship at Penn State University. The project was designed to explore how AI, real-time market information, technical indicators, and automated decision-making can be combined into a paper-trading system.

## Project Overview

The application collects and analyzes market data to generate automated trading signals. It uses technical indicators along with current market information and news to help determine whether a stock should be bought, sold, or held.

The project also includes a web-based dashboard that allows users to view market information, analyze selected stocks, and track simulated trades without using real money.

## Key Features

- Real-time stock market data retrieval
- Market news integration
- Automated Buy, Sell, and Hold signals
- Paper-trading system with simulated portfolio tracking
- Technical indicator calculations
- Stock selection and analysis
- API-based communication between the application and market data
- Web-based trading dashboard
- Trade history and portfolio value tracking
- Testing and troubleshooting of data and trading logic

## Technical Indicators

The application uses several indicators when analyzing stocks:

- RSI (Relative Strength Index)
- SMA20 (20-Day Simple Moving Average)
- MACD (Moving Average Convergence Divergence)
- Momentum
- Daily price change

These indicators are used together to help the system evaluate current market conditions and generate trading signals.

## How It Works

1. Market data is collected for selected stock tickers.
2. The application processes historical and current price information.
3. Technical indicators such as RSI, SMA20, MACD, and momentum are calculated.
4. Current market news and additional information can be incorporated into the analysis.
5. The system evaluates the available information and generates a Buy, Sell, or Hold signal.
6. Trades can be simulated through the paper-trading dashboard.
7. Portfolio value, holdings, and trade history are updated as simulated trades occur.
